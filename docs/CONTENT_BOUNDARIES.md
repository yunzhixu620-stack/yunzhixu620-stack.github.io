# 合规、授权与隐私公开边界

本文是产品公开边界，不替代针对具体业务和地区的专业法律、医疗或信息安全意见。

## AnyDiagnosis：医疗辅助原型

公开页面必须持续展示：

- 这是产品展示和交互原型，不用于真实诊断或治疗；
- AI 输出不是医疗建议，候选诊断、置信度和证据链均未代表完成临床验证；
- 最终医疗决定不能由原型自动执行。

进入真实研发前至少完成：

1. 明确预期用途、使用者、使用环境和禁止用途；
2. 判断产品是否属于医疗器械及其分类，制定注册、临床评价和质量管理路径；
3. 建立模型版本、数据版本、性能分层、失败降级和上市后监测；
4. 将医疗健康数据作为敏感个人信息处理，执行最小必要、单独告知同意、权限隔离、访问审计、传输与存储保护；
5. 对高风险、低置信度、资料缺失、急危重症和模型不可用场景设计人工升级路径。

## 校招测评题库：内容授权与质量

数据质量和传播权利是两件不同的事情。即使题目已成功结构化，也不能自动推定可以公开再传播。

公开扩大前至少完成：

1. 为每个来源记录文件名、提供者、授权状态、允许用途和下架联系人；
2. 对企业真题、机构题库、解析文本和图片分别核对权利状态；
3. 页面提供来源说明、纠错入口和权利人下架请求方式；
4. 无法确认的内容保持隔离，不进入普通练习、搜索推荐或商业化内容；
5. 用户进度默认保存在本地；若增加云同步，先说明数据范围、保留期限、导出和删除方式。
